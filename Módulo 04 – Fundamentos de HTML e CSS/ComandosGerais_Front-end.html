Referência Front-end

HTML · CSS · JavaScript · Acessibilidade

Estrutura do documento
<!DOCTYPE html>Declara o tipo do documento como HTML5
<html lang="">Elemento raiz. O atributo lang define o idioma da páginaex: <html lang="pt-BR">
<head>Metadados, título, links de CSS e scripts (não aparece na tela)
<body>Todo o conteúdo visível da página
<meta charset="UTF-8">Define codificação de caracteres (suporta acentos e símbolos)
<meta name="viewport">Controla o zoom em dispositivos móveisex: content="width=device-width, initial-scale=1.0"
<title>Título exibido na aba do navegador
<link rel="stylesheet">Importa um arquivo CSS externo
<script src="">Importa um arquivo JavaScript externo
<script defer>Carrega o JS após o HTML ser lido (evita bloqueio)
Texto e semântica
<h1> a <h6>Títulos hierárquicos. Importante para SEO e acessibilidade
<p>Parágrafo de texto
<span>Agrupa texto inline para estilização
<strong>Texto em negrito com importância semântica
<em>Texto em itálico com ênfase semântica
<small>Texto secundário ou de menor importância
<mark>Texto destacado (fundo amarelo por padrão)
<code>Trecho de código inline
<pre>Bloco de texto com espaços e quebras preservados
<blockquote>Citação em bloco
<br>Quebra de linha
<hr>Linha horizontal separadora
Listas
<ul>Lista não ordenada (marcadores)
<ol>Lista ordenada (números)
<li>Item de lista
<dl> / <dt> / <dd>Lista de definição: termo e descrição
Links e mídia
<a href="">Link para outra página ou âncora
<a target="_blank">Abre o link em nova aba
<img src="" alt="">Imagem. O atributo alt é obrigatório para acessibilidade
<picture>Container para imagens responsivas com múltiplas fontes
<video controls>Vídeo com controles de reprodução
<audio controls>Áudio com controles de reprodução
<iframe src="">Incorpora outra página ou conteúdo externo (ex: Google Maps)
<source>Define fontes alternativas para video, audio ou picture
Formulário
<form action="" method="">Define um formulário e para onde os dados vão
<input type="text">Campo de texto simples
<input type="email">Campo de e-mail com validação automática
<input type="password">Campo de senha (oculta o texto)
<input type="number">Campo numérico
<input type="checkbox">Caixa de seleção (múltipla escolha)
<input type="radio">Botão de opção (escolha única)
<input type="file">Campo para upload de arquivo
<input type="date">Seletor de data
<input type="range">Controle deslizante (slider)
<input type="hidden">Campo invisível para enviar dados ocultos
<input placeholder="">Texto de dica exibido quando o campo está vazio
<input required>Campo obrigatório (valida antes de enviar)
<input disabled>Campo desabilitado (não editável)
<label for="">Rótulo vinculado a um campo pelo id
<button type="submit">Botão que envia o formulário
<button type="button">Botão sem ação padrão (usado com JavaScript)
<button type="reset">Limpa todos os campos do formulário
<select> / <option>Lista de opções (dropdown)
<textarea>Campo de texto com múltiplas linhas
<fieldset> / <legend>Agrupa campos relacionados com um título
Tabela
<table>Define uma tabela
<thead> / <tbody> / <tfoot>Agrupa cabeçalho, corpo e rodapé da tabela
<tr>Linha da tabela
<th>Célula de cabeçalho (negrito por padrão)
<td>Célula de dado
colspan / rowspanMescla colunas ou linhas da tabelaex: <td colspan="2">
Layout semântico
<div>Bloco genérico sem significado semântico
<header>Cabeçalho da página ou seção
<nav>Bloco de navegação (menus e links)
<main>Conteúdo principal único da página
<section>Seção temática da página
<article>Conteúdo independente (post, notícia, card)
<aside>Conteúdo lateral ou complementar
<footer>Rodapé da página ou seção
Atributos globais comuns
id=""Identificador único do elemento (usado em CSS e JS)
class=""Classe CSS (pode ser reutilizada em vários elementos)
style=""CSS inline aplicado diretamente ao elemento
data-*Armazena dados personalizados no elementoex: data-id="42" — acessado via JS com dataset.id
hiddenEsconde o elemento da página
title=""Tooltip que aparece ao passar o mouse
Seletores
elementoSeleciona todas as tags daquele tipoex: p { color: red; }
.classeSeleciona elementos com aquela classe
#idSeleciona o elemento com aquele id (único)
*Seleciona todos os elementos da página
pai filhoSeleciona descendentesex: div p (qualquer p dentro de div)
pai > filhoSeleciona apenas filhos diretos
el1, el2Seleciona múltiplos elementos de uma vez
:hoverAplica estilo quando o mouse está sobre o elemento
:focusAplica estilo quando o elemento está focado (ex: input)
:activeAplica estilo no momento do clique
:first-childSeleciona o primeiro filho do elemento pai
:last-childSeleciona o último filho
:nth-child(n)Seleciona o enésimo filhoex: :nth-child(2) ou :nth-child(odd)
:not(seletor)Seleciona elementos que não correspondem ao seletor
::before / ::afterInsere conteúdo antes ou depois do elemento (requer content:)
::placeholderEstiliza o texto de placeholder de inputs
Texto e fonte
colorCor do textoex: color: #333 / color: red / color: rgb(0,0,0)
font-sizeTamanho da fonte (px, rem, em, %)
font-weightEspessura da fonte (normal, bold, 100–900)
font-familyTipo de fonte usada
font-styleEstilo da fonte (normal, italic)
text-alignAlinhamento: left, center, right, justify
text-decorationDecoração: underline, none, line-through
text-transformTransforma texto: uppercase, lowercase, capitalize
line-heightEspaçamento entre linhas
letter-spacingEspaçamento entre letras
word-spacingEspaçamento entre palavras
white-spaceControla quebra de linha: nowrap, pre, normal
overflow: hidden + text-overflow: ellipsisCorta texto longo com "..." no final
Cores e fundo
background-colorCor de fundo do elemento
background-imageImagem de fundoex: url('imagem.jpg')
background-sizeTamanho do fundo: cover, contain, 100%
background-positionPosição do fundo: center, top, left
background-repeatRepetição do fundo: no-repeat, repeat-x, repeat-y
background (shorthand)Todas as propriedades de fundo em uma linhaex: background: url() no-repeat center/cover
opacityTransparência do elemento inteiro (0 a 1)
Borda
borderBorda em uma linhaex: border: 1px solid #ccc
border-radiusArredonda os cantosex: 8px ou 50% para círculo
border-color / border-width / border-styleCor, espessura e estilo da borda separadamente
border-top / right / bottom / leftBorda em apenas um lado
outlineContorno externo (não ocupa espaço, comum em focus)
box-shadowSombra ao redor do elementoex: 0 2px 8px rgba(0,0,0,0.2)
Tamanho e espaçamento
width / heightLargura e altura do elemento
max-width / min-widthLimites de largura
max-height / min-heightLimites de altura
paddingEspaço interno (entre conteúdo e borda)ex: padding: 10px 20px (vertical horizontal)
marginEspaço externo ao redor do elementoex: margin: 0 auto (centraliza bloco)
box-sizing: border-boxPadding e border não aumentam o tamanho total do elemento
Display e visibilidade
display: blockOcupa a linha inteira, aceita width/height
display: inlineFica na mesma linha, não aceita width/height
display: inline-blockFica na mesma linha mas aceita width/height
display: noneEsconde o elemento e remove o espaço dele
visibility: hiddenEsconde o elemento mas mantém o espaço
overflowComportamento do conteúdo que ultrapassa: hidden, scroll, auto
Posicionamento
position: staticPadrão. Segue o fluxo normal do documento
position: relativePosicionado em relação a si mesmo. Não sai do fluxo
position: absolutePosicionado em relação ao pai com position. Sai do fluxo
position: fixedFixo na tela. Não move com o scroll
position: stickyGruda na tela ao rolar até ele (ex: menu fixo)
top / right / bottom / leftDeslocamento do elemento posicionado
z-indexOrdem de sobreposição (maior fica na frente)
Transição e animação
transitionAnimação suave ao mudar uma propriedadeex: transition: all 0.3s ease
transformTransforma o elemento: rotate, scale, translate, skewex: transform: rotate(45deg)
@keyframesDefine uma animação com etapas (from/to ou porcentagens)
animationAplica uma animação @keyframes ao elementoex: animation: nome 1s ease infinite
Variáveis e responsividade
--nome-varDeclara uma variável CSS (custom property)ex: --cor-principal: #4a90d9
var(--nome-var)Usa o valor de uma variável CSS
@media (max-width: Npx)Aplica estilos só até certa largura de tela (responsividade)
@media (min-width: Npx)Aplica estilos a partir de certa largura de tela
Outros
cursorTipo do cursor: pointer, default, not-allowed, grab
pointer-events: noneDesativa cliques e hover no elemento
user-select: noneImpede que o texto seja selecionado pelo usuário
resizePermite redimensionar o elemento: none, both, vertical
object-fitComo imagens se ajustam ao container: cover, contain, fill
Flexbox — container
display: flexAtiva o layout flexível no elemento pai
flex-directionDireção dos filhos: row, row-reverse, column, column-reverse
justify-contentAlinha no eixo principal: flex-start, center, flex-end, space-between, space-around, space-evenly
align-itemsAlinha no eixo cruzado: flex-start, center, flex-end, stretch, baseline
align-contentAlinha múltiplas linhas (quando flex-wrap está ativo)
flex-wrapQuebra para nova linha: nowrap, wrap, wrap-reverse
gapEspaço entre os filhosex: gap: 16px ou gap: 8px 16px (linha coluna)
Flexbox — filhos
flex-growQuanto o filho cresce para preencher o espaço disponível
flex-shrinkQuanto o filho encolhe quando falta espaço
flex-basisTamanho inicial do filho antes de crescer/encolher
flex (shorthand)Atalho para grow shrink basisex: flex: 1 (cresce igualmente)
align-selfSobrescreve align-items para um filho específico
orderMuda a ordem visual do filho sem alterar o HTML
Grid — container
display: gridAtiva o layout em grade no elemento pai
grid-template-columnsDefine as colunas da gradeex: 1fr 1fr 1fr ou repeat(3, 1fr)
grid-template-rowsDefine as linhas da grade
gap / column-gap / row-gapEspaço entre colunas e linhas do grid
justify-itemsAlinha o conteúdo das células horizontalmente
align-itemsAlinha o conteúdo das células verticalmente
repeat(n, tamanho)Repete colunas ou linhasex: repeat(4, 1fr)
auto-fit / auto-fillCria colunas automaticamente conforme o espaço disponívelex: repeat(auto-fit, minmax(200px, 1fr))
minmax(min, max)Define tamanho mínimo e máximo de uma coluna ou linha
Grid — filhos
grid-columnDefine em quais colunas o filho se posicionaex: grid-column: 1 / 3 (ocupa colunas 1 e 2)
grid-rowDefine em quais linhas o filho se posiciona
grid-column: 1 / -1O elemento ocupa todas as colunas da grade
justify-self / align-selfAlinha um filho específico dentro de sua célula
Variáveis
varDeclara variável (escopo global/função). Evite usar hoje
letDeclara variável que pode ser reatribuída (escopo de bloco)
constDeclara constante que não pode ser reatribuída
Tipos de dados
StringTextoex: "Olá" ou 'Olá' ou `Olá ${nome}`

ArrayLista de valoresex: [1, 2, 3] / ["a", "b"]

Funções

Boas práticas
label for + input idAssocia o rótulo ao campo. Clicando no label, o input é focado
:focusSempre defina um estilo de foco visível para navegação por teclado
contraste de coresTexto deve ter contraste mínimo de 4.5:1 com o fundo (WCAG AA)
não use só corNão transmita informação apenas pela cor (adicione ícone ou texto)
ordem lógica de headingUse h1 → h2 → h3 em sequência. Não pule níveis
lang no htmlDefina sempre o idioma: <html lang="pt-BR">
