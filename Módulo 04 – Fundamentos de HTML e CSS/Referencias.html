Referência HTML & CSS

Estrutura
<!DOCTYPE html>Declara o tipo do documento como HTML5
<html>Elemento raiz da página
<head>Contém metadados, título e links (não aparece na tela)
<body>Todo o conteúdo visível da página fica aqui
<meta charset>Define a codificação de caracteres (geralmente UTF-8)
<title>Define o título exibido na aba do navegador
<link>Liga um arquivo externo à página (ex: CSS)
<script>Inclui código JavaScript na página
Texto
<h1> a <h6>Títulos e subtítulos (h1 é o maior, h6 o menor)
<p>Parágrafo de texto
<span>Agrupa texto inline sem quebrar linha
<strong>Texto em negrito (importância semântica)
<em>Texto em itálico (ênfase semântica)
<br>Quebra de linha
<hr>Linha horizontal separadora
Listas
<ul>Lista não ordenada (com marcadores)
<ol>Lista ordenada (numerada)
<li>Item de lista (usado dentro de ul ou ol)
Links e mídia
<a href="">Link para outra página ou âncora
<img src="">Exibe uma imagem
<video>Incorpora um vídeo na página
<audio>Incorpora um áudio na página
Formulário
<form>Define um formulário
<input>Campo de entrada (texto, email, senha, número etc.)
<label>Rótulo para um campo de formulário
<button>Botão clicável
<select>Lista de opções (dropdown)
<option>Opção dentro de um select
<textarea>Campo de texto multilinha
Tabela
<table>Define uma tabela
<tr>Linha da tabela
<th>Célula de cabeçalho (negrito e centralizado por padrão)
<td>Célula de dado comum
<thead> / <tbody>Agrupa cabeçalho e corpo da tabela
Layout
<div>Bloco genérico para agrupar elementos
<header>Cabeçalho da página ou seção
<nav>Menu de navegação
<main>Conteúdo principal da página
<section>Seção temática da página
<footer>Rodapé da página ou seção
Texto
colorDefine a cor do texto
font-sizeTamanho da fonte (px, rem, %)
font-weightEspessura da fonte (normal, bold, 100–900)
font-familyTipo de fonte usada
text-alignAlinhamento do texto (left, center, right, justify)
text-decorationDecoração do texto (underline, none, line-through)
line-heightEspaçamento entre linhas
letter-spacingEspaçamento entre letras
Fundo e borda
background-colorCor de fundo do elemento
background-imageImagem de fundo
borderBorda do elemento (largura, estilo, cor)
border-radiusArredonda os cantos do elemento
border-colorCor da borda
border-widthEspessura da borda
box-shadowSombra ao redor do elemento
Tamanho e espaçamento
width / heightLargura e altura do elemento
max-width / min-widthLargura máxima e mínima
paddingEspaço interno entre o conteúdo e a borda
marginEspaço externo ao redor do elemento
box-sizingDefine como largura/altura incluem padding e borda
Display e posicionamento
displayTipo de exibição: block, inline, flex, grid, none
positionPosicionamento: static, relative, absolute, fixed
top / right / bottom / leftDeslocamento quando o elemento está posicionado
z-indexDefine qual elemento fica na frente quando se sobrepõem
overflowControla o conteúdo que ultrapassa o elemento (hidden, scroll, auto)
Flexbox
display: flexAtiva o layout flexível no container
flex-directionDireção dos itens: row (horizontal) ou column (vertical)
justify-contentAlinha itens no eixo principal (center, space-between etc.)
align-itemsAlinha itens no eixo cruzado (center, flex-start etc.)
gapEspaço entre os itens do flex ou grid
flex-wrapPermite que os itens quebrem para a próxima linha
Outros
cursorTipo de cursor ao passar o mouse (pointer, default etc.)
opacityTransparência do elemento (0 = invisível, 1 = opaco)
transitionAnimação suave ao mudar uma propriedade CSS
visibilityMostra ou esconde o elemento sem remover o espaço (visible, hidden)
