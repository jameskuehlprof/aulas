1)BAIXAR o JAVA SDK e instalar: https://www.oracle.com/br/java/technologies/downloads/#jdk25-windows - x64 Installer
Após a instalação configurar as variáveis de ambiente do windows onde foi instalado:
JAVa_HOME: C:\Program Files\Java\jdk-25.0.2
PATH: C:\Program Files\Java\jdk-25.0.2\bin
Para testar se funcionou o JAVA, após a instalação e configuração o comando: java -version  no prompt de comando deverá trazer a versão do JAVA.
